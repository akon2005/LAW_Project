The signed-in workspace has six tabs in the top navigation bar.

| Tab | What it is for |
|---|---|
| **Research** | The main workflow: ask a legal question, read the retrieved records and the grounded answer. |
| **Statutes & Articles** | A browsable reference list of instruments from the bundled dataset. Clicking a row runs a search for it. |
| **Documents** | The 25 most recent records in the bundled dataset, with a preview action. |
| **Compare** | Weigh two competing accounts of the same dispute against retrieved precedents. |
| **Knowledge** | The Open Knowledge Format (OKF v0.2) bundle: curated concepts derived from the indexed corpus. |
| **Settings** | Appearance (interface mode, colour palette, custom palette) and the account facts for the session you are signed in with. |

Other controls:

* **About** (top right) toggles the "research support only" notice bar.
* The **user chip** (top right) shows the signed-in identity, whether the session
  is a verified server session or a local demo session, and **Sign out**.
* The **sparkle button** in the bottom-right corner opens this support assistant.
* The **footer** repeats the record count and a link to the same notice.

There is no separate dashboard page: the Research tab is the workspace. If a
guide mentions a page you cannot find in that list, the page does not exist in
this build — tell the assistant and it will report the gap instead of inventing
a route.
