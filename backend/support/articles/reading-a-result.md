Clicking a record (or its **Read** button) opens a full-screen reading view.

| Control | Options |
|---|---|
| Text size | 80%-240%, plus a reset |
| Line spacing | compact / normal / relaxed |
| Column width | narrow / standard / wide / full |
| Typeface | serif / sans |
| Reader theme | light / sepia / dark |

Also available: **Copy text**, **Print**, and previous/next navigation between the
records currently in the result list.

Keyboard: `+` and `-` change the text size, `0` resets it, the arrow keys move
between records, and `Esc` closes the view.

Your reader preferences persist in this browser under `vidhiveda.reader` in
`localStorage`, so they survive a reload. The text-size control in the results
toolbar drives the same scale for the cards and the answer panel.

The reading view shows the stored chunk text. It does not summarise, rewrite or
extend it — what you read is what the corpus holds.
