## What it is

An **example gallery** of approved prompts, grouped by category, for showing how
VIDHIVEDA responds. Every example states:

* its category and title,
* the exact prompt to run,
* the learning objective,
* the expected response characteristics,
* whether running it invokes a real backend capability,
* whether it is **based on verified project data** or **illustrative**.

## Where to find it

* In the workspace, under the **Guides** action in the support assistant.
* In the support assistant itself: the **Explore Examples** quick action, or by
  asking for an example.

Each card offers **Load into chat**, which puts the prompt into the assistant's
input box for you to send, and **Try this example**, which runs it.

## Live versus illustrative

Examples that exercise a real capability (documentation search, feature status,
system status, a support question) call the actual support backend. Examples about
legal reasoning are labelled **illustrative educational example**: they explain
how you would approach the question and are explicitly not a legal result, so no
fake judgment, citation or prediction is ever produced.

## Honest demo rules

* Nothing stages a fake live search or a fake prediction.
* Where a capability does not exist — an outcome estimate, for instance — the demo
  shows the honest disclosure instead of inventing a result.

See the teacher demonstration script in `docs/support-assistant.md`.
